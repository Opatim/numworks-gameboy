# &#x20;Game Boy sur NumWorks

Ce dépôt explique comment installer **PeanutGB**, un émulateur Game Boy, sur une calculatrice **NumWorks**.

##

---

## &#x20;1. Télécharger PeanutGB

Le projet PeanutGB pour NumWorks est développé par **Nwagyu** :

\- [https://github.com/nwagyu/peanutgb](https://github.com/nwagyu/peanutgb)

Ouvre la page **Releases** du projet et télécharge le dernier fichier :

```text
peanutgb.nwa
```

---
![Télécharger PeanutGB](images/peanutgb-download.png)

## &#x20;2. Installer PeanutGB sur la NumWorks

Va sur :

👉 [https://my.numworks.com/apps](https://my.numworks.com/apps)

Connecte ta calculatrice NumWorks à ton ordinateur avec un câble USB.

Depuis la page NumWorks, envoie le fichier :

```text
peanutgb.nwa
```

sur la calculatrice.

## &#x20;4. Contrôles

Les commandes sont les suivantes :

| Game Boy | NumWorks  |
| -------- | --------- |
| ↑ ↓ ← →  | Flèches   |
| A        | Back      |
| B        | OK        |
| Select   | Shift     |
| Start    | Backspace |

### Autres touches

| Touche | Fonction                         |
| ------ | -------------------------------- |
| `1`    | Palette Game Boy originale       |
| `2`    | Palette niveaux de gris          |
| `3`    | Palette niveaux de gris inversée |
| `+`    | Utiliser tout l'écran            |
| `-`    | Affichage à l'échelle 1:1        |
